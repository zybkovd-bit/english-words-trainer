# WordSpeller — тренажёр английских слов

Открой `index.html` в браузере (или на телефоне) — больше ничего не нужно.

1. Вкладка **«Мои слова»**: вставь слова по одному на строку, например `apple - яблоко`
   (можно вставить из Excel или загрузить .txt/.csv), нажми **«Сохранить и начать»**.
2. Вкладка **«Тренировка»**: видишь русское слово — пишешь английское и жмёшь Enter.
   - Правильно — поле загорается зелёным, и идёт следующее слово.
   - Неправильно — поле загорается красным: твоё слово и правильное (ошибочные буквы подсвечены)
     видны 3 секунды, потом оба плавно исчезают, и слово нужно написать заново.
   - «Показать ответ» — слово видно постоянно; кнопка меняется на «Скрыть ответ», чтобы убрать подсказку.
3. В конце круга — счёт «с первого раза» и кнопка **«Повторить ошибки»**.

Опция «Проверять по буквам»: неверная буква загорается красным и стирается. После 3 неверных попыток
одной и той же буквы слово показывается на 2 секунды, потом снова скрывается.
Список слов сохраняется в браузере.

Опция «Повтор без ошибок» (появляется, когда включена проверка по буквам): если слово дописано,
но по пути были неверные буквы, его нужно набрать ещё раз. Следующее слово появится только после
попытки без единой ошибки.

## Пакеты слов

Слева выбираешь, сколько слов учить за раз: 5, 10, 15, 20 или все. Каждое слово пакета — кружок с номером:

- зелёный **Знаю · I know** — написал с первого раза без ошибок;
- оранжевый **Средне · So-so** — первая буква верная, ошибка дальше;
- красный **Не знаю · Don't know** — ошибка уже в первой букве (или подсмотрел ответ до того, как начал писать).

Зелёные слова больше не спрашиваются (и запоминаются в браузере). Оранжевые и красные повторяются кругами,
пока каждое не будет написано с первого раза без ошибок. Потом — «Следующий пакет».
Прогресс можно сбросить во вкладке «Мои слова».
