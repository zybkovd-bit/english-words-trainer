# WordSpeller — тренажёр английских слов

Открой `index.html` в браузере (или на телефоне) — больше ничего не нужно.

1. Вкладка **«Мои слова»**: вставь слова по одному на строку, например `apple - яблоко`
   (можно вставить из Excel или загрузить .txt/.csv), нажми **«Сохранить и начать»**.
2. Вкладка **«Тренировка»**: видишь русское слово — пишешь английское и жмёшь Enter.
   - Правильно — поле загорается зелёным, и идёт следующее слово.
   - Неправильно — поле загорается красным, правильное слово показывается на 3 секунды
     (ошибочные буквы подсвечены) и скрывается; слово нужно написать заново.
   - «Показать ответ» — слово видно постоянно, пока не напишешь его правильно.
3. В конце круга — счёт «с первого раза» и кнопка **«Повторить ошибки»**.

Опция «Проверять по буквам»: неверная буква загорается красным и стирается. После 3 неверных попыток
одной и той же буквы слово показывается на 2 секунды, потом снова скрывается.
Список слов сохраняется в браузере.
